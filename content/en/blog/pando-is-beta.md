---
title: Pando is beta for now
date: 2026-04-26
tags: ["Beta", "Community"]
---

Pando is under very active development; at this moment, a large part of the current code improvements are already programmed by the software itself.

Many bugs are still expected if you try it, which is expected as there are still many things to test and refine. If you want to be a beta tester, you are welcome.

Use Github issues if you have any problems, detailing the bug and how to reproduce it: [https://github.com/digiogithub/pando/issues](https://github.com/digiogithub/pando/issues). Also include the version you are using.
